# 킨다 브랜드 전략서

## 1. 문서 목적과 사용법

이 문서는 `킨다`를 소개하고 판매할 때 사용하는 최소 공통 기준이다. 제품 소개서, 제안서, 웹·앱, 설치 문서, 장비 라벨과 파트너 영업 자료는 아래 정의와 표현 원칙을 따른다. 기능 범위와 검증 상태는 [프로젝트 현황](../project-status.md) 및 [메뉴별 현황](../menus/)을 먼저 확인한다.

## 2. 브랜드 정의

| 항목 | 기준 |
| --- | --- |
| 브랜드 | **킨다** — 회사가 직접 출시·운영하는 단독 마스터브랜드 |
| 범주 | 주차장·시설용 스마트 조명 운영 솔루션 |
| 1순위 고객 | 조명 시공·유통 파트너 |
| 최종 사용자 | 시설 관리자, 건물주·구매 담당자, 현장 운영자 |
| 해결할 문제 | 설치 이후 조명 상태와 제어 이력이 흩어져 파트너의 인수인계·유지관리와 고객의 운영 판단이 복잡해지는 문제 |
| 브랜드 약속 | 조명의 설치부터 운영까지 필요한 정보를 연결해, 파트너는 쉽게 제안·인계하고 고객은 한눈에 확인·제어하게 한다. |

**포지셔닝 문장**

킨다는 주차장·시설 조명을 공급하는 시공·유통 파트너를 위해 설치 정보, 제어, 모니터링과 운영 통계를 하나로 연결하는 스마트 조명 운영 솔루션이다.

## 3. 핵심 메시지 계층

1. **파트너 가치:** 제안부터 설치, 인수인계, 유지관리까지 하나의 브랜드와 운영 흐름으로 설명할 수 있다.
2. **최종 고객 가치:** 여러 조명과 현장의 상태를 한눈에 확인하고 필요한 대상을 바로 제어할 수 있다.
3. **근거:** 현장·층·도면 기반 관리, 개별·그룹 제어, 상태 모니터링, 운영 통계, 게이트웨이 기반 연결과 이력 관리.

근거는 현재 구현 및 검증 범위 안에서만 사용한다. 실제 장비에서 검증하지 않은 안정성·통신 성능·자동화 결과를 보장하지 않으며, 측정 전 에너지 절감률이나 비용 절감액을 제시하지 않는다.

## 4. 공식 소개 문구

- **짧은 소개:** 조명 운영을 간단하게 만드는 스마트 조명 솔루션, 킨다.
- **표준 소개:** 킨다는 주차장과 시설의 조명을 설치 정보부터 제어, 모니터링, 운영 통계까지 하나로 연결하는 스마트 조명 운영 솔루션입니다.
- **제안서용:** 킨다는 시공·유통 파트너가 조명 설치 이후의 인수인계와 유지관리를 체계화하고, 최종 고객이 현장 상태를 한눈에 확인하고 필요한 조명을 제어할 수 있도록 돕습니다.

**공식 슬로건:** 조명 운영을 간단하게.

**보조 카피**

- 설치부터 운영까지, 하나로 연결합니다.
- 한눈에 확인하고 필요한 곳을 바로 제어하세요.
- 파트너의 설치 경험과 고객의 운영 경험을 함께 생각합니다.

`조명을 킨다`는 브랜드 유래 또는 단기 캠페인에만 사용하며 핵심 약속이나 상시 슬로건으로 사용하지 않는다.

## 5. 브랜드 성격과 보이스

브랜드 성격은 **명료한 실무자**, **신뢰할 수 있는 기술 파트너**, **과장하지 않는 안내자**다.

| 원칙 | 사용 | 지양 |
| --- | --- | --- |
| 짧고 구체적으로 쓴다 | `B2층 조명 3개의 상태를 확인해 주세요.` | `혁신적인 통합 기술로 완벽하게 관리합니다.` |
| 사용자의 다음 행동을 알려준다 | `게이트웨이 연결을 확인한 뒤 다시 시도해 주세요.` | `오류가 발생했습니다.` |
| 확인된 사실만 말한다 | `최근 수집된 전력 사용량을 비교합니다.` | `전기료를 30% 절감합니다.` |
| 기술어는 필요한 만큼만 쓴다 | `조명 연결 상태` | `BLE Mesh 노드 텔레메트리 상태` |

## 6. 명명 및 공동 표기 규칙

- 공식 표기는 한글 **`킨다`**를 우선한다. `KINDA`는 URL, 앱 식별자, 영문 파일명 등 한글 사용이 어려운 곳의 보조 표기다.
- 기능·제품은 별도 브랜드를 늘리지 않고 `킨다 관제`, `킨다 게이트웨이`, `킨다 컨트롤러`, `킨다 모바일`처럼 기능형으로 명명한다.
- 파트너 자료에서도 서비스 브랜드는 `킨다`로 유지한다. 파트너 정보는 `공급·시공 및 문의: 파트너사명` 형식으로 분리한다.
- `파트너사명 킨다`, `파트너사명에서 만든 킨다`처럼 소유 주체를 오해하게 만드는 결합 표기는 사용하지 않는다.
- 운영 회사명은 계약서, 약관, 개인정보 처리방침, 저작권·사업자 정보 등 법적·운영 고지가 필요한 위치에 표기한다.

## 7. 시각 방향

승인된 방향은 **O안 `스위치 플립` 심벌과 오션 코랄 팔레트를 결합한 절제된 코랄 체계**다. 안정적인 라운드 프레임은 운영 시스템, 들린 타일은 조명을 켜는 동작, Coral 면은 점등, Blue 깊이는 디지털 제어를 뜻한다. 한글 워드마크를 중심으로 시공·유통 파트너가 신뢰할 수 있는 명료한 B2B 실무형 인상을 만든다. 정사각 마크는 54px 시안의 비례를 64px 안전 영역 안에 보존하고 소형·단색 환경에서 식별성을 검증한다.

| 역할 | 색상 | 기준 |
| --- | --- | --- |
| 기본 문자·짙은 배경 | Navy `#15324A` | 본문, 제목, 정보 위계와 짙은 브랜드 면에 사용한다. |
| 주요 행동·상호작용 | Blue `#256FA1` | 링크, 주요 버튼과 선택·활성 상호작용에 사용한다. |
| 브랜드 강조 | Coral `#FF7A5C` | 로고 심벌, 강조 그래픽과 선택적 장식에만 사용한다. |
| 기본 밝은 배경 | Paper `#F4F8FA` | 넓은 배경과 중립 브랜드 면에 사용한다. |

- 브랜드 색상 면적은 **Navy 60%, Blue 30%, Coral 10% 이하**를 기준으로 한다. 이 비율은 개별 화면을 기계적으로 채우는 규칙이 아니라 브랜드 접점 전체의 시각 무게를 조절하는 가이드다.
- 확인된 명암비는 Navy/White `13.23:1`, Blue/White `5.43:1`, Coral/White `2.56:1`, Coral/Navy `5.16:1`, Navy/Paper `12.38:1`이다.
- Coral은 흰 배경의 본문, 주요 버튼, 성공·경고·오류 등의 상태 의미색으로 사용하지 않는다. 제품의 주요 행동은 Blue, 본문은 Navy를 사용하고 성공·경고·오류는 브랜드 Coral과 분리된 의미 색상 토큰으로 전달한다.
- 색상만으로 선택이나 상태를 구분하지 않고 텍스트, 아이콘, 테두리 또는 형태를 함께 사용한다.
- 장식적인 빛 번짐, 흔한 전구 그림과 일반 전원 아이콘의 직접 묘사는 피한다. 화면, 인쇄물, 장비 라벨에서 같은 인상을 유지할 수 있도록 가로형·단색형·반전형·소형 아이콘 규격을 함께 만든다.

상세 제작 및 검증 기준은 [킨다 시각 아이덴티티 설계](../superpowers/specs/2026-09-13-kinda-visual-identity-design.md)를 따른다.

## 8. 우선 적용 접점

1. 파트너용 제품 소개서·영업 제안서
2. 데모, 로그인과 제품 화면의 브랜드 영역
3. 설치 가이드·현장 체크리스트·인수인계 문서
4. 게이트웨이·컨트롤러 라벨과 QR 안내
5. 견적서·제품 사양서
6. 홈페이지·고객지원 페이지

현재 앱과 배포 자산에 남아 있는 `LED Control`은 임시 표기로 보고 후속 브랜드 적용 작업에서 교체한다. 이 문서는 앱 파일의 즉시 변경을 승인하지 않는다.

## 9. 금지·주의사항

- 실측 근거 없이 에너지 절감률, 비용 절감액, 통신 성공률, 장애 감소율을 수치로 주장하지 않는다.
- 자동 테스트나 mock 결과를 실장비 검증 결과로 표현하지 않는다.
- `완벽한`, `무조건`, `업계 최고`, `고장 없는` 등 입증하기 어려운 절대 표현을 사용하지 않는다.
- 킨다를 단순 점등 앱으로 축소해 설명하지 않는다.
- 파트너 로고가 킨다보다 상위 브랜드처럼 보이거나, 반대로 파트너의 공급·시공 책임이 보이지 않는 공동 표기를 피한다.

## 10. 출시 전 검증 체크리스트

- [ ] 국내 상표, 도메인과 주요 채널 식별자 사용 가능성을 확인했다.
- [ ] 시공·유통 파트너가 10초 안에 서비스 범주와 고객 가치를 설명할 수 있다.
- [ ] 소개서, 데모, 설치 문서, 장비 라벨에서 `킨다` 표기와 제품명이 일치한다.
- [ ] 파트너 공동 표기가 서비스 소유와 공급·시공 주체를 명확히 구분한다.
- [ ] 모든 기능·성능 문구를 실제 구현 상태 및 검증 증거와 대조했다.
- [ ] 에너지·비용 절감 문구에 측정 조건, 기준 기간과 근거 데이터가 있다.
- [ ] 한글 워드마크, 단색형과 소형 표기가 화면·인쇄·장비에서 식별된다.
- [ ] Navy `#15324A`, Blue `#256FA1`, Coral `#FF7A5C`, Paper `#F4F8FA`가 지정된 역할과 사용 비율을 따른다.
- [ ] Coral이 흰 배경 본문, 주요 버튼 또는 상태 의미색에 사용되지 않았다.
- [ ] 본문·상호작용·상태 표시가 목표 명암비를 충족하며, 색상 외의 텍스트·아이콘·형태로도 의미가 전달된다.
- [ ] 로고를 `16px`, `24px`, `32px`, 단색, 반전, 흑백과 실제 장비 라벨 크기에서 검증했다.
- [ ] 최종 한글 서체와 영문·숫자 보조 서체의 상업적 사용 및 배포 라이선스를 확인했다.
- [ ] 기존 `LED Control` 표기의 교체 대상과 순서를 목록화했다.
