## Sub-Agent Delegation Rules
- 단일 파일 수정, 유닛 테스트 작성, 단순 코드 리뷰, 린트 에러 수정 등 5분 이내의 독립적인 태스크는 직접 처리하지 말고 반드시 **서브 에이전트를 생성(spawn)**하여 위임하세요.
- 메인 에이전트는 오케스트레이터(Orchestrator) 역할에 집중하고, 서브 에이전트의 결과물만 취합하여 `writing-plans` 체크리스트를 업데이트하세요.
- 작업 중 필요하다고 판단되는 경우 직접 이 파일을 업데이트 하세요.


## Coding GuideLines

### 공통
- 모든 코드는 재사용 가능하며 반복적이지 않고 가독성이 좋도록 항상 유지하세요.
- 예외 사항 및 일반적인 경우를 따르지 않는 로직의 경우 반드시 주석을 통해 상세하게 명시하세요.

### Frontend
- 버튼, 카드 같은 재사용 가능한 컴포넌트는 꼭 공통 컴포넌트의 형태로 분리해서 하나의 폴더에 모아주세요.

### Backend
- db 스키마 및 구조가 변경되는 경우 database-schema.md 파일을 새롭개 갱신해주세요.
