# Control Panel Stable Feedback Design

## Goal

PC 제어 화면에서 조명을 선택하거나 조건부 상태 문구가 나타나도 우측 제어 카드의 상태 배지와 핵심 입력 UI가 잘리거나 밀리지 않게 한다.

## Approved design

- 대상명과 상태 배지는 우측 카드 상단의 고정 헤더로 유지한다.
- 대상 요약, 밝기, 프리셋, override 시간, 적용 버튼은 선택 상태 변화와 무관하게 같은 위치를 유지하며, 높이가 낮은 PC에서는 전용 본문 안에서 스크롤해 모두 접근할 수 있게 한다.
- 제어 불가 사유, 명령 전송 메시지, 진행 카드와 조회 오류는 항상 존재하는 전용 피드백 영역 안에 렌더링한다.
- PC 2열 레이아웃에서는 헤더, 제어 본문, 피드백을 독립 행으로 두고 본문과 피드백 내용이 각 영역보다 길면 해당 영역 안에서 스크롤한다.
- 전체 문서에는 세로 스크롤을 만들지 않으며 긴 대상명과 상태 배지는 카드 경계를 벗어나지 않는다.
- 1120px 이하의 단일 열 레이아웃에서는 기존 문서 흐름과 모바일 접근성을 유지한다.

## Verification contract

- 1440x900, 1121x900 및 1366x768에서 조명 선택 전후 핵심 입력의 위치가 변하지 않는다.
- 제어 불가 조명을 선택했을 때 상태 배지와 차단 사유가 우측 카드 경계 안에 보인다.
- 긴 조명 이름도 상태 배지를 카드 밖으로 밀어내지 않는다.
- 조건부 피드백이 표시되어도 문서 세로 스크롤은 생기지 않는다.
