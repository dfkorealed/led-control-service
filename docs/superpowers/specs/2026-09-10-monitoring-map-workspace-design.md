## 동작 계약

- 상단 KPI는 `전체 조명`, `정상`, `점검 필요` 3개만 표시한다. `평균 밝기`와 별도 `빠른 상태` 영역은 제거한다.
- 지도는 데스크톱에서 남은 작업 영역 전체 높이를 사용한다.
- 지도는 확대, 축소, 100% 화면 맞춤 버튼을 제공한다. `Ctrl`/`Cmd` + 휠로 포인터 위치를 기준으로 확대·축소하고, 일반 스크롤과 드래그로 상하좌우 이동한다.
- 100%는 현재 지도 viewport 안에 원본 비율을 유지해 맞춘 크기다. 확대하면 내부 scroll extent가 함께 증가한다.
- 조명 marker 선택은 지도 드래그와 충돌하지 않는다.
- 우측 패널은 공통 `SidePanel`과 레이아웃 클래스를 사용한다. 하위 grid/flex item은 `min-width: 0`, 긴 값은 패널 안에서 줄바꿈, 높이가 제한된 화면에서는 패널 내부만 세로 스크롤한다.
- 1120px 이하에서는 지도/본문 다음에 우측 패널을 쌓고 문서 스크롤을 허용한다.

## 영향 범위

- 모니터링: KPI, 지도 조작, 상세 패널
- 제어: 밝기 실행 우측 패널
- 통계: 비용 비교 우측 패널
- 설정: 맵 편집 우측 속성 패널
- 문서: `docs/menus/monitoring.md`, `control.md`, `statistics.md`, `settings.md`

## 제외 범위

- 지도 편집 기능을 모니터링에서 활성화하지 않는다.
- API, 데이터 모델, 저장 형식은 변경하지 않는다.
- 실제 하드웨어 연동 범위는 변경하지 않는다.
