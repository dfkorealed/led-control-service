# 킨다 랜딩 대안 시안 디자인 브리프

## 목적

현재의 밝은 분할형 시안과 구조가 다른, 토스의 간결한 메시지 전달을 참고한 킨다 B2B 랜딩 예시 세 개를 비교한다. 시설 운영 담당자와 시공·유통 파트너가 조명 관제의 가치와 상담 경로를 이해할 수 있어야 한다.

## 공통 사실과 제한

- 토스에서 참고할 것은 큰 타이포그래피, 섹션당 하나의 메시지, 제품 화면과 문장의 결합, 스크롤 리듬이다. 토스의 문구·브랜드 자산·영상은 쓰지 않는다.
- 기능은 현장·층·도면에서 조명 위치와 최근 상태 확인, 개별·그룹 점등/밝기 제어와 일정, 명령 처리 이력, 상태 기반 추정 전력 범위에서 설명한다.
- 절감률, 고객 로고, 도입 기간, 호환성, 자동 등록, 실측 전력 같은 검증되지 않은 약속은 하지 않는다.
- 영상 없이 CSS/SVG/HTML 기반 정적 화면과 짧은 등장 효과만 사용한다. 축소 동작 설정을 존중한다.
- 세 페이지 모두 독립적인 검토용 정적 파일이다. 제품 API와 상담 API를 호출하지 않으며 상담 CTA는 기존 `/#contact`에 연결한다.
- 기존 `/` 랜딩은 변경하지 않는다.

## 대안 1: 관제실

짙은 남색의 몰입형 첫 화면에 현장 도면을 크게 놓고 조명 상태 카드를 겹친다. 화면 아래에는 찾기·제어·확인을 짧은 수평 흐름으로 보여준다. 운영 관제의 안정감과 기술적 신뢰를 앞세운다.

## 대안 2: 에디토리얼

밝은 종이색 바탕, 압도적인 글자 크기, 선과 번호를 사용한 편집 디자인이다. 첫 화면은 제품 미리보기보다 메시지를 크게 선언하고, 다음 화면에서 전체 폭 관제 장면을 펼친다. 문장과 여백으로 브랜드 인상을 만든다.

## 대안 3: 현장의 하루

일과의 흐름을 따라 점검 시작 → 운영 조정 → 결과 확인 장면을 세로 타임라인으로 구성한다. 각 장면에 작은 UI 패널과 운영자의 질문을 배치한다. 제품 기능을 처음 보는 구매자가 실제 사용 맥락을 쉽게 이해하도록 한다.

## 완료 기준

- 세 시안의 첫 화면과 섹션 구조가 시각적으로 뚜렷하게 다르다.
- 320px부터 데스크톱까지 가로 넘침이 없고 헤딩·CTA가 읽힌다.
- 상담 CTA가 `/#contact`를 가리킨다.
- 갤러리에서 세 시안과 기존 시안을 한 번에 열 수 있다.
- 예시 데이터임을 표시하고 실제 제품 기능처럼 클릭 가능한 가짜 조작을 만들지 않는다.
