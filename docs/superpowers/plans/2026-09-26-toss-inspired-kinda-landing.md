# 킨다 랜딩 개편 계획: 토스의 전달 방식 참고

**상태:** 방향 검토용 초안. 현재 `/` 랜딩은 이 계획으로 바꾸지 않았다.

**예시 페이지:** [독립 콘셉트 페이지](../../../apps/web/public/concepts/toss-inspired-landing.html) · 로컬 서버에서는 `http://localhost:5173/concepts/toss-inspired-landing.html`

**참고:** [토스 홈페이지](https://toss.im/)를 2026-09-26에 확인했다. 한 장면에 한 핵심 문장을 두고, 짧은 설명과 제품 화면을 결합하는 서술 방식, 넓은 여백과 강한 타이포그래피, 스크롤에 따라 이어지는 장면 구성을 참고한다. 토스의 영상, 문구, 브랜드 자산은 사용하지 않는다.

## 목표와 판단 기준

- 시설 운영 담당자와 시공·유통 파트너에게 **위치 파악 → 제어 → 결과 확인**의 실제 업무 흐름을 30초 안에 이해시킨다.
- 기능 이름을 나열하는 대신 기능이 현장 업무에서 어떤 판단을 돕는지 짧게 설명한다.
- 첫 화면에서 제품의 형태를 보여주고, 마지막에는 기존의 페이지 내 상담 양식으로 연결한다.
- 영상 없이 정적인 관제 화면 구성 예시와 가벼운 등장 애니메이션만 사용한다.
- 확인되지 않은 절감률·고객사·도입 기간·실시간 알림·하드웨어 호환성을 주장하지 않는다. 전력은 **상태 기반 추정치**로만 소개한다.

## 화면 설계

| 구간 | 핵심 문장 | 시각 자료 | 고객이 이해할 이점 |
| --- | --- | --- | --- |
| 첫 화면 | 조명 운영을 한눈에 | 도면·선택 조명·상태가 보이는 큰 관제 화면 | 제품이 무엇인지 즉시 파악 |
| 01 찾기 | 어디에 있는지, 바로 찾을 수 있도록 | 현장·층과 검색 결과 | 점검 대상을 현장 맥락에서 찾음 |
| 02 제어 | 하나씩, 혹은 함께 | 개별·그룹·밝기·일정 화면 | 대상과 시간을 구분해 운영 |
| 03 확인 | 명령을 보낸 뒤에도, 결과를 확인 | 명령 처리 이력 | 조치 결과를 다시 확인 |
| 마무리 | 우리 현장에도 맞을까요? | 단일 상담 CTA | 현장별 도입 대화로 이동 |

## 시각 및 동작 원칙

- 킨다의 남색·파랑·코럴 로고 색을 유지하고, 밝은 바탕과 넉넉한 여백을 사용한다.
- 한 섹션에 제목 하나, 설명 한 단락, 시각 자료 하나, 운영 이점 한 문장을 기본 단위로 한다.
- 스크롤 시 섹션 내용을 한 번만 부드럽게 드러낸다. 자동 순환, 영상, 과한 패럴랙스는 넣지 않는다.
- `prefers-reduced-motion`에서는 효과 없이 모든 내용을 바로 보여준다.
- 실제 제품 UI와 유사한 예시임을 분명히 하며, 예시 수치나 상태를 실제 고객 데이터처럼 표시하지 않는다.
