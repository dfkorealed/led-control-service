# 모바일 맵 배치 구현 계획

> 기존 `FloorEditorView`/`FloorEditorCanvas`의 승인된 08 시안을 구현한다. 작은 TDD 단위로 진행하며 다른 담당자의 공통 UI·셸·API 파일은 수정하지 않는다.

**목표:** 모바일에서 미배치 조명을 `선택 → 맵 탭 → 위치 확인 → 저장` 순서로 배치하고, 편집 정보 패널의 기본 화면을 도구·선택 속성 중심으로 정리한다.

**구조:** 미배치 목록은 배치 요청만 상위 편집기에 전달한다. 캔버스는 기존 카메라 변환으로 탭 좌표를 계산하되, 확인 전에는 store를 수정하지 않는다. 확인은 기존 `placeFixtures`를 호출하고 기존 저장·lease·409 복구를 재사용한다.

**기술:** React, Zustand, Konva, Vitest/Testing Library. 승인 시안: `docs/assets/ux-refresh-2026-09-23/08-mobile-map-placement.png`.
