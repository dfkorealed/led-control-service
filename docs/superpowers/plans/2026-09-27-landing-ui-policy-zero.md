# 랜딩 UI 정책 위반 0건 전환 실행 계획

실행 시 superpowers:subagent-driven-development 또는 superpowers:executing-plans를 적용하고, 이 체크리스트와 docs/project-status.md를 함께 갱신한다.

목표: 공개 랜딩의 UI 정책 위반 927건을 기존 화면·동작과 정책을 유지한 채 0건으로 줄인다.

구성: React 화면은 승인된 토큰과 유틸리티로 옮기고, 정적 시안은 실제 배포 경로를 보존하는 적법한 구조로 전환한다. DOM 질의는 ref로 바꾼다.

기술: React 18, TypeScript, Tailwind 4, Vite, Vitest, Playwright.

## 작업 경계

- 기준 커밋 04de3375fd01be502f4389712ed1a6d882f86eb2의 격리 작업 트리 codex/landing-ui-policy에서만 수정한다.
- UI 정책 스크립트, 위반 0 기준값, 검토된 테마 토큰과 신뢰 앵커를 임의로 바꾸지 않는다.
- 데스크톱·모바일 배치, 색상, 서체, 반응형 기준, 애니메이션과 상담·로그인 동작을 보존한다.
- 스타일을 검사 대상 밖 파일에 숨기거나 기능 삭제·광범위 예외로 수치를 없애지 않는다.
- 320·390·1024·1440px 화면, 인증 화면으로의 스타일 누출, 포커스·터치·드래그·상담 동작을 확인한다.

## 정책·화면 동일성 검토

- [x] 활성 CSS 919건을 분류했다: 금지 선택자 481건, 간격 237건, 서체 164건, 원시 색상 32건, 폼 선택자 4건, 파일 자체 1건이다.
- [x] 승인 토큰과 정확히 일치하지 않는 대표 값은 히어로 제목 최대 78px, 작은 문구 13px, 브랜드 22px, 430·720·1050px 화면 전환, 18px 반경과 18px/55px 그림자다. 가까운 승인 유틸리티로 대체하면 화면이 달라진다.
- [x] 활성 CSS에는 서로 다른 font-size 표현 36종, 줄 간격 14종, 자간 20종, 반경 23종, 그림자 20종이 있다. 승인 간격 단계 밖 픽셀 수치만 57종·175회다. 이 수치는 토큰 검토 범위이며 리터럴마다 토큰을 만들자는 제안이 아니다.
- [ ] 미적용 토큰 검토 후보: 히어로 1규칙에 --text-landing-hero-fluid: clamp(55px, 5.3vw, 78px), 장면 문구 1규칙에 --text-landing-eyebrow: 13px(13px 전체 7회), 상담 팝업 1곳에 --radius-landing-dialog: 18px, 데모 카드 선언·사용 각 1곳에 --shadow-landing-card: 0 18px 55px rgb(21 50 74 / .10), 세 화면 전환에 --breakpoint-landing-narrow: 26.875rem, --breakpoint-landing-stack: 45rem, --breakpoint-landing-wide: 65.625rem을 검토한다. 나머지 서체·간격 역할과 정책 계약도 검토가 필요하다.
- [ ] 막힘: 기존 화면을 정확히 유지한 0건 전환에는 검토된 의미 기반 토큰·화면 전환 기준과 컴포넌트 스타일링 계약이 필요하다. 이 작업에서 정책이나 토큰을 임의 변경하지 않는다.
