# 현장의 하루 인터랙티브 랜딩 시안

기준일: 2026-09-26

## 목표

비교 갤러리의 네 번째 시안(`/concepts/field-day.html`)을 킨다 웹 디자인 시스템 색상으로 재구성하고, 기업 구매자가 모니터링·제어·통계·맵 편집의 운영 흐름을 한 화면씩 이해할 수 있는 인터랙티브 예시로 만든다. 정적 시안으로서 실제 현장 API나 인증 API를 호출하지 않는다.

## 작업 체크리스트

- [x] `field-day.html`의 헤더·히어로·섹션을 재구성한다. 헤더 로그인은 `/login`으로 연결한다.
- [x] `theme.css`의 브랜드·표면·텍스트·상태 색상값을 토대로 시안 CSS를 정리하고 데스크톱 장면을 최소 한 뷰포트 높이로 배치한다. 작은 화면은 내용이 잘리지 않도록 늘어난다.
- [x] 모니터링 조명 선택, 제어 밝기 적용, 통계 그래프 그리기, 보고서 미리보기, 맵 배치 예시를 만든다. 각 장면은 진입 시 한 번 재생하고 다시 보기와 실제 조작을 지원한다.
- [x] `prefers-reduced-motion`에서 자동 움직임을 생략하고 최종 상태를 보이게 한다. 버튼·범위 입력과 상태 안내는 키보드·스크린리더로 접근할 수 있게 한다.
- [x] 비교 갤러리와 `docs/menus/landing.md`에서 네 번째 시안 설명·관련 파일·예시 한계를 최신화한다.
- [x] 브라우저에서 데스크톱·모바일 배치, 애니메이션, 조작, 로그인·상담 링크 및 가로 넘침을 확인한다.

## 범위 판단

기존 공개 랜딩(`/`)과 운영 메뉴 구현은 변경하지 않는다. 통계 그래프는 상태 기반 추정치의 가상 예시이며 보고서와 맵 편집도 설명용 데모다. 확인되지 않은 절감률·실측값·자동 등록 약속은 넣지 않는다.

## 2026-09-26 브라우저 피드백 반영

- [x] 고정 헤더에서 제품 살펴보기 항목을 제거하고, 스크롤 위치에서도 상담·로그인 동선이 유지되는지 확인한다.
- [x] 히어로 카드의 그래프 막대와 포인터에 느린 움직임을 추가하고, 모든 장면의 애니메이션을 화면 재진입마다 처음부터 재생한다.
- [x] 장면 제목 위 작은 문구를 키우고, MONITORING 배경 글자 간격을 넓히며, 맵 편집 장면의 “다음 현장”을 제거한다.
- [x] 맵 편집 예시에 도구에서 도면으로 끌어 놓기와 도면 안에서 조명 위치 이동을 보여준다. 도면 밖 드롭은 기존 배치를 유지한다.
- [x] `docs/menus/landing.md`를 최신화하고 데스크톱·모바일·축소 동작·재진입 재생을 검증한다.
