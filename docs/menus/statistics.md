# 통계 메뉴 기능 현황

기준일: 2026-07-05

## 구현 완료

- `useEnergyEstimate`로 전력 추정 API 데이터를 조회한다.
- 일, 월, 년 사용량 kWh를 표시한다.
- 일, 월, 년 예상 전기료를 표시한다.
- 기간별 사용량을 막대 차트 형태로 표시한다.
- 월 예상 전기료 기반 운영 인사이트 문구를 표시한다.
- 추정 집계 상태를 UI에 표시한다.

## 미구현

- 실제 meter 또는 fixture state 기반 전력 사용량 적산
- 일/월/년 기간 선택
- 사용자 지정 기간 조회
- 층별 전력 사용량 차트
- 그룹별 전력 사용량 차트
- 조명별 전력 사용량 상세
- 전기요금 단가/요금제 설정 연동
- 피크/경부하/중간부하 시간대 요금제
- 절감률 산정 근거 표시
- CSV/Excel/PDF 내보내기
- 통계 drill-down
- 전월 대비, 전년 대비 비교

## 부족하거나 개선이 필요한 기능

- 현재 차트 높이는 실제 데이터 비율 계산이 아니라 고정값에 가깝다.
- 절감 지표 `18%`, 피크 시간 `18:00-22:00`, 추천 정책 `야간 60%`는 실제 분석 결과가 아니다.
- 에너지 추정 API가 실제 command/fixture 이력과 연결되어 있는지 추가 검증이 필요하다.
- 예상 전기료는 단일 단가 기반이며 복합 요금제를 반영하지 않는다.
- 통계 화면의 기준 현장, 기준 기간, 마지막 집계 시간이 표시되지 않는다.
