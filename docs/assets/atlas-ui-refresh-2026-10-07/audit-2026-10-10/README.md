## 유지해야 하는 차이

- 실제 CAD·조명 수·현장 데이터가 목업과 다른 것은 디자인 오류가 아니다. 가짜 parking SVG, virtual Gateway, 예시 초기화, 결과 시나리오는 제품에 이식하지 않는다.
- 명시적 적용, 대상/밝기 draft, 권한·오프라인 차단, UUID·진행/오류·복구, 스케줄과 BIO 실제 필드, 등록/편집 lease, 미저장 guard를 유지한다.
- 통계 null과 0, 실제 기간·수집률·저장 비용·forecast, 보고서 job/서명 URL/실제 파일 수명을 유지한다. 목업에만 있는 필터·이름·미리보기·순간 완료를 만들지 않는다.
- 목업에 없는 실제 기능도 삭제하지 않고 같은 공통 표현으로 정돈한다. API·DB·Gateway·펌웨어·실장비 변경은 없다.
- 표/카드 재사용이 현재 배치를 보존한다는 뜻은 아니다. pill 탭과 그룹 DataGrid 등 확인된 표현 차이는 수정한다.
