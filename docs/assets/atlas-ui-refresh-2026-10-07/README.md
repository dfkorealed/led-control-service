목업은 visual companion의 `/files/` 경로와 전역 가상 데이터를 사용하므로 이 복사본을 직접 열거나 제품 번들에 연결하는 방식은 지원하지 않는다. 파일은 색상·배치·컴포넌트 표현의 근거를 보존하기 위한 것이다.

인라인 도면 상태, 도면 내부 선택 도구, PC 수동 제어 높이 조정은 이 자료에 반영돼 있다. 최신 모바일 헤더 로고·현장 선택 너비 수정은 아직 목업에 적용되지 않았으며 기준 명세의 추가 요구를 따른다. 가상 시나리오, mock 집계·도면·Gateway·보고서와 목업의 제어 대상 제외 정책을 실제 서비스에 이식하지 않는다.
